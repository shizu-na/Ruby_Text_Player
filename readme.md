# Ruby Text Player | 多言語テキスト学習プレイヤー

**全14言語（台湾華語・中国語・広東語・台湾語・韓国語・日本語・英語・ドイツ語・フランス語・スペイン語・ロシア語・アラビア語・ペルシア語・タイ語）**に対応した、**ビルド不要・ブラウザだけで動作する多言語テキスト学習プレイヤー**です。

🌐 **Web版（GitHub Pages）**: [https://shizu-na.github.io/Ruby_Text_Player/](https://shizu-na.github.io/Ruby_Text_Player/)  
（ブラウザ上でそのまま使えるほか、リポジトリ一式をダウンロードして `index.html` を直接開いてもオフライン環境で完全動作します）

ニュース・物語・日常会話・スピーチ・古典詩・伝統民謡など、あらゆる外国語の文章に対して、AI（Gemini や ChatGPT など）に内蔵プロンプトを貼り付けて学習データを生成し、このアプリに登録することで、単語・語節ごとの発音・ルビ（注音／ピンイン／粤拼／台羅／発音ハングル／ふりがな／IPA等）・意味・文法解説を確認しながら学習できます。

## ファイル構成

ビルドツールや外部フレームワークに依存しない、役割ごとに整理された4ファイル構成です（`file://` での直接起動・GitHub Pages の両方に対応）。

| ファイル | 役割 |
|---|---|
| `index.html` | アプリの画面構造（ヘッダー・メイン表示・プレイヤーバー・各シート・SVGアイコン） |
| `styles.css` | デザイントークン（ライト／ダークテーマ）、多言語タイポグラフィ、RTL・ルビレイアウト |
| `content-data.js` | **定数・文言・テンプレート集約ファイル**（初期サンプル教材、14言語カタログ `LANG_CATALOG`、AI変換プロンプト `PROMPT_TEMPLATES`、画面メッセージ・トースト文言 `UI_TEXT`） |
| `app.js` | アプリ本体のロジック（パーサー、DOM描画、Web Speech API 音声合成、ライブラリ管理、共有・重複解決） |

## 主な特徴

- **環境構築ゼロ・オフライン完全動作**
  - インストールやビルド作業は不要。GitHub Pages で開くか、`index.html` をブラウザで開くだけで使えます。
  - オンライン時は Google Fonts を非同期で適用し、オフライン時は端末内蔵フォントへ自動フォールバックするため、電波のない場所でもレイアウト崩れや読み込み待ちが発生しません。
- **メタデータタグ標準化 ＆ 100%後方互換の自動判別**
  - 学習データの先頭に `【言語】de-DE`、`【タイトル】`、`【出典】`（または `【著者】`）等を記述することで全14言語を確実に判別し、バッジ・表示項目ラベル・読み上げ音声（Web Speech API）・書字方向（LTR / RTL）をテキストごとに自動で切り替えます。
  - 旧形式のタグ（`【曲名】` `【歌手】` `【アーティスト】` 等）や、`【言語】` タグがない既存データも文字種（注音・ハングル・ピンイン・かな）から自動判別されるため、100%後方互換を保ちます。
- **2つのトークナイズ＆描画モード（文字分割モード ／ 単語一体モード）**
  - **文字分割モード（`華` `中` `粤` `台` `韓` `日`）**：単語ごとのスペース区切り（`好(ㄏㄠˇ) 一朵(ㄧˋ ㄉㄨㄛˇ) 美麗(ㄇㄟˇ ㄌㄧˋ)`）を1つの単語箱（`.word`）にしつつ、内部は1文字ずつルビを割り振って描画します。文字数と音節数が合わない児化音（`花兒(huār)`）や熟字訓（`今日(きょう)`）は自動でグループルビにフォールバックします。また、過去の「1文字ずつスペース区切り」データも語彙リストの最長一致で従来通りグループ化されます。
  - **単語一体モード（`EN` `DE` `FR` `ES` `RU` `AR` `FA` `TH`）**：1単語に対して1つのIPAルビを中央配置し、アラビア語・ペルシア語の文字結合（リガチャ）やタイ語の上下声調記号を崩さずに保持します。タップ単位も自動的に「単語ごと」に最適化されます。
  - **スペースをまたぐ連語・熟語の連動（`data-span`）**：韓国語の `걷고 싶네요`、ドイツ語の `auf der Heiden`、英語のイディオムなど、複数語にまたがる表現が【単語・文法解説】にある場合、下線でつながり、どの単語をタップしても連語全体がハイライト＆発音されます。
  - **RTL（右から左）＆ 双方向テキスト（BiDi）保護**：アラビア語・ペルシア語では行が右から左（`dir="rtl"`）に流れ、文中に英語フレーズ等が混在しても語順が反転しないよう自動で `<span class="ltr-run" dir="ltr">` に保護されます。また、アラビア語の母音記号（シャクル／タシュキール）の有無を問わず語彙解説と自動照合します。
- **厳格なTTSボイス照合 ＆ サイレント学習モード**
  - 端末に該当言語の音声（Web Speech API）が存在しない場合（台湾語 `nan-TW` など）、無関係な言語の音声で誤読せず、自動的に**サイレント学習モード（音声なし・ルビ＆意味トースト表示）**で動作します。全行連続再生時も文字数に応じたタイマーでスムーズに行送りされます。
- **AIプロンプト生成機能（全14言語フラット選択）**
  - アプリ内のAI変換用プロンプト作成シートから、14言語すべてをワンタップで選択可能。`【言語】` `【タイトル】` `【出典】` タグや各言語固有の発音・原形解説ルールが組み込まれたプロンプトを即座に生成します。
- **OS標準の共有シート連携（Web Share API）・JSONバックアップ・重複防止**
  - **テキストコピー ＆ OS共有シート連携**: 1件のテキストやAI変換プロンプトをクリップボードにコピーできるほか、スマートフォン等の Web Share API 対応環境では **「共有」** ボタンから LINE・メモ帳・Keep・AirDrop 等の他アプリへ直接送信できます。
  - **複数件を選択してJSON保存・共有**: マイライブラリの「選択して書き出し」から、共有したいデータだけにチェックを入れてJSONファイル（`ruby_text_selected_Nitems_YYYY-MM-DD.json`）として保存、またはOSの共有シート経由でGoogleドライブ・ファイルアプリ・LINE等へ直接渡せます。
  - **全件JSONバックアップ**: マイライブラリの「JSONバックアップ」から、全データの書き出し（`ruby_text_library_YYYY-MM-DD.json`）・共有・読み込みに対応しています。
  - **スマート重複排除 ＆ 衝突確認ダイアログ**: JSONファイルの統合時やテキスト追加時に、「言語＋タイトル＋出典」の正規化キーで既存データを自動照合します。中身まで100%同一のデータは自動でスキップし、**「同じタイトルで内容が異なるデータ」があった場合は確認ダイアログが表示され、「別名（`(2)` など）にして両方残す」「新しい内容で上書き」「重複分はスキップ」を安全に選択**できます。

## データの保存仕組みとプライバシーについて

- **データは各自のブラウザ内（`localStorage`）にのみ保存されます**
  - GitHub Pages 等のWeb上で公開されているURLを利用しても、あなたが追加・編集したテキストデータは**お使いの端末のブラウザ内部にだけ保存**され、外部サーバーに送信されたり他人に公開されたりすることは一切ありません。
- **PC ⇔ スマートフォン間のデータ移動・バックアップ**
  - ブラウザごとに保存領域が独立しているため、PCで作ったデータをスマホに移したい場合や、友人に渡したい場合は、以下のいずれかの方法で簡単に共有・統合できます。
    1. **1件だけ送る場合**：「このテキストをコピー」または「このテキストを共有」でLINEやメモ帳に送り、受け取り側の「新しいテキストを追加」画面で **「貼り付け」** を押す。
    2. **複数件まとめて送る・バックアップする場合**：「マイライブラリ」→ **「選択して書き出し」**（またはJSONバックアップ）から **「共有」** / **「JSON保存」** を行い、受け取り側の「JSONバックアップ」→ **「読み込み」** で統合する（複数件のテキストやJSON文字列をそのままテキスト追加欄に貼り付けて一括追加することも可能です）。

## 使い方

### 1. アプリを開く
[GitHub Pages](https://shizu-na.github.io/Ruby_Text_Player/) にアクセスするか、ダウンロードしたフォルダ内の `index.html` をPCまたはスマートフォンのブラウザ（Chrome / Safari / Edge など）で開きます。

### 2. AIで学習データを作る
1. 画面右上の **「＋」**（新しいテキストを追加）内の **「AI用プロンプト」**、または **「⋯」メニュー →「AI変換用プロンプトを作成」** を開きます。
2. 14言語のチップから対象の言語を選び、変換したい外国語の文章（ニュース・物語・日常会話など）を貼り付けます（空欄のままでも可）。
3. **「コピーしてテキスト追加へ」**（スマホでは **「共有」** からAIアプリへ直接渡すことも可能）を押します。
4. Gemini や ChatGPT にプロンプトを貼り付けて送信し、出力されたコードブロック内のテキストをコピーします。

### 3. テキストを登録・学習する
1. 「新しいテキストを追加」画面の **「貼り付け」** ボタンを押すか、テキスト欄にAIが出力したテキストを貼り付けます。
2. `【言語】` `【タイトル】` `【出典】` `【URL】` が自動認識され、言語モード・行数・語彙数がリアルタイム表示されます。
3. **「保存して開く」** を押すとライブラリに追加されます。
4. 本文の単語（または文字）をタップすると、ネイティブ音声で読み上げられると同時に、発音記号と意味のプレビューが表示されます。

## 学習テキストのフォーマット仕様

AIを使わず手動で作成・編集する場合も、以下のプレーンテキスト形式に従えば自動でパースされます。
（※後方互換性のため、旧タグ `【曲名】` `【歌手】` `【アーティスト】` 等で記述されたデータもそのまま読み込めます）

### 華語（繁体字・注音）の例

```text
【言語】zh-TW
【タイトル】茉莉花
【出典】傳統民歌
【URL】https://...（任意）

好(ㄏㄠˇ) 一朵(ㄧˋ ㄉㄨㄛˇ) 美麗(ㄇㄟˇ ㄌㄧˋ) 的(ㄉㄜ˙) 茉莉花(ㄇㄛˋ ㄌㄧˋ ㄏㄨㄚ)
hǎo yì duǒ měi lì de mò lì huā
なんと美しいジャスミンの花。

【単語・文法解説】
- 好 (ㄏㄠˇ / hǎo)：なんと～、実に～（感嘆を表す副詞）。
- 一朵 (ㄧˋ ㄉㄨㄛˇ / yì duǒ)：一輪（数量詞）。
- 美麗 (ㄇㄟˇ ㄌㄧˋ / měi lì)：美しい（形容詞）。
- 的 (ㄉㄜ˙ / de)：～な（構造助詞）。
- 茉莉花 (ㄇㄛˋ ㄌㄧˋ ㄏㄨㄚ / mò lì huā)：ジャスミンの花（名詞）。
```

### 韓国語（ハングル・音韻変化反映）の例

```text
【言語】ko-KR
【タイトル】天気の良い日の会話
【出典】韓国語日常会話

오늘은(오느른) 날씨가(날씨가) 정말(정말) 좋아서(조아서) 같이(가치) 걷고(걷꼬) 싶네요(심네요)
oneureun nalssiga jeongmal joaseo gachi geotgo simneyo
今日は天気が本当に良いので、一緒に歩きたいですね。

【単語・文法解説】
- 오늘은 (오느른 / oneureun)：【原形：오늘（今日）＋ 은（〜は）】今日は（名詞＋補助詞）。パッチム「ㄹ」が後ろの母音「은」と連音化して「오느른」と発音される。
- 날씨가 (날씨가 / nalssiga)：【原形：날씨（天気）＋ 가（〜が）】天気が（名詞＋主格助詞）。
- 정말 (정말 / jeongmal)：本当に、実に（副詞）。
- 좋아서 (조아서 / joaseo)：【原形：좋다（良い）＋ -아서（〜なので）】良くて、良いので。語幹末のパッチム「ㅎ」が母音の前で弱化（脱落）し「조아서」と発音される。
- 같이 (가치 / gachi)：一緒に、共に（副詞）。パッチム「ㅌ」が母音「이」と出会い口蓋音化して「가치」と発音される。
- 걷고 싶네요 (걷꼬 심네요 / geotgo simneyo)：【原形：걷다（歩く）＋ -고 싶다（〜したい）＋ -네요（〜ですね）】歩きたいですね（連語）。「걷고」はパッチム「ㄷ」の後ろで濃音化し「걷꼬」、「싶네요」はパッチム「ㅍ[ㅂ]」が「ㄴ」の前で鼻音化し「심네요」と発音される。
```

### 欧州言語・アラビア語・タイ語（単語一体モード）の例

```text
【言語】de-DE
【タイトル】Heidenröslein
【出典】Johann Wolfgang von Goethe

Sah(zaː) ein(aɪn) Knab(knaːp) ein(aɪn) Röslein(ˈrøːslaɪn) stehn(ʃteːn), Röslein(ˈrøːslaɪn) auf(aʊf) der(deːɐ̯) Heiden(ˈhaɪdən)
zaː aɪn knaːp aɪn ˈrøːslaɪn ʃteːn ˈrøːslaɪn aʊf deːɐ̯ ˈhaɪdən
ひとりの少年が小さなバラが咲いているのを見た、野原に咲く小さなバラを。

【単語・文法解説】
- Sah (zaː)：【原形：sehen（見る）】見た（3人称単数過去形）。
- Knab (knaːp)：【原形：der Knabe（少年）】少年（男性名詞・主格）。
- Röslein (ˈrøːslaɪn)：【原形：das Röslein（小さなバラ）】小さなバラ（中性名詞・4格）。
- stehn (ʃteːn)：【原形：stehen（立っている・咲いている）】立っていること（不定詞）。
- auf der Heiden (aʊf deːɐ̯ ˈhaɪdən)：【原形：die Heide（荒野・野原）】野原の上に（前置詞句）。
```
